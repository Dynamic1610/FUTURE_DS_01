# Business Sales Performance Analytics Dashboard

## 📌 Project Overview

This project analyzes retail sales data to identify **sales trends, profitability, top-performing products, and regional performance**.

The project was completed as part of the **Future Interns Data Science & Analytics Internship – Task 1**.

## 🛠️ Tools & Technologies

* **Python** – Data cleaning and preprocessing
* **Google Colab** – Data analysis and preparation
* **Power BI** – Interactive dashboard and data visualization
* **Pandas** – Data manipulation
* **CSV** – Dataset format

## 📊 Dataset

The project uses the **Sample Superstore** dataset, which contains information about:

* Orders
* Customers
* Products
* Categories and sub-categories
* Sales
* Profit
* Discounts
* Regions and locations

## 🔍 Key Analysis

The analysis focuses on:

* Total Sales and Total Profit
* Sales and profit trends
* Category and sub-category performance
* Regional performance
* Top-performing products
* Impact of discounts on profitability
* Identification of areas with low or negative profit

## 📈 Dashboard

An interactive Power BI dashboard was created to provide a clear overview of business performance and help identify important sales and profitability patterns.

### Key KPIs

* **Total Sales**
* **Total Profit**
* **Total Orders**
* **Average Order Value**

## 💡 Key Insights

The dashboard helps answer questions such as:

* Which categories generate the most sales?
* Which products and sub-categories are most profitable?
* Which regions perform best?
* Where are losses occurring?
* How do discounts affect profitability?
* What sales trends can be observed over time?
